# Đố Vui Màn Ảnh

Thư viện quiz kiến thức phim. Phim đầu tiên: **Đầu Xuân Tươi Sáng** (2026), 21 câu hỏi, mỗi lượt 12 câu ngẫu nhiên.

## Thêm phim mới

Mở `index.html`, thêm một object vào mảng `FILMS` (gồm `id`, `title`, `original`, `meta`, `sources`, `questions`). Mỗi câu hỏi có `q` (câu hỏi), `a` (đáp án đúng), `w` (3 đáp án sai), `e` (giải thích).
